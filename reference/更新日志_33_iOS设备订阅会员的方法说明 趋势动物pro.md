# iOS设备订阅会员的方法说明 | 趋势动物pro

因为iOS系统相关法规，  
您暂时无法在iOS终端订阅趋势动物pro会员  
  
以下是替代方法：  
  
1、在PC端打开小程序 → 趋势动物pro  
2、正常订阅会员并支付  
3、订阅会员后，手机端将自动同步会员权益  
  
小程序内的会员权益和微信号绑定  
在Android、iOS、Mac、Windows体系下都可以正常使用。
