# 20260508 版本更新

小程序新版本2.8.4 更新  
  
1、增加了收藏夹分组功能  
🔹用户可以自建分组，更好管理如持仓、观察池等需求  
🔹支持批量修改分组、移除分组、取消收藏  
🔹支持手动修改分组排序、可见性  
🔹会员用户享受系统自动分组：近期收藏、大类分组。  
系统自动分组方式：当你某个大类收藏的品种超过20个后，系统会自动分组，每天轮询一次。  
  
2、修复了分享-趋势图的bug  
🔹电脑端可以保存高清趋势图  
🔹趋势图的顺序被固定下来  
  
3、修复了其他错误。
