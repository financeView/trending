# 更新 | “温转热”标签上线

"温转热"标签已上线，覆盖全品种。   
  
标签含义：当天趋势温度由温转热——  
换句话说，右侧被开启或延续确认。  
  
举个例子，最新一个交易日（前天，周五），  
受A股带动，港股、美股同一天趋势温转热，确认了右侧的延续。
