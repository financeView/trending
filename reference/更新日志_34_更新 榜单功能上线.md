# 更新 | 榜单功能上线

榜单功能上线。  
以杭州为例，所有城市适用  
  
1、租息榜单  
  
杭州高租息板块Top10榜单  
杭州低租息板块Top10榜单  
杭州高租息主力小区Top50榜单  
  
2、近半年涨跌榜单  
  
杭州上涨主力小区Top50榜单  
杭州下跌主力小区Top50榜单  
  
3、趋势温度榜单  
  
杭州趋势右侧主力小区Top50清单  
杭州趋势右侧板块Top10清单  
  
4、趋势强度榜单  
  
杭州高趋势强度主力小区Top50榜单  
杭州高趋势强度板块Top10榜单  
  
注：主力小区，是指高流通小区，要求小区年网签套数超过10套  
  
入口：全国房产>杭州>杭州榜单
