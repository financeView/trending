# 如何使用趋势动物pro小程序

小程序入口：趋势动物pro  
  
创作趋势小程序的三个初衷：  
  
1、追踪全市场、全天候的趋势工具。  
  
覆盖全市场大类：房、股、商、债、衍。  
全国房产周度更新、金融资产交易日更新。  
  
如果您只关注房产，  
推荐您将自己关注的城市设为主页。  
  
如果您关注全大类资产，  
推荐您将“大类资产”设为主页，图2  
涵盖房股商债全市场，日频更新，可横向比较趋势。  
  
2、为顺势交易者提供决策参考。  
  
核心指标是[趋势温度](https://mp.weixin.qq.com/s?__biz=MzkyODQ5MTIzNw==&mid=2247484004&idx=1&sn=3570fde6439546defab30a96a9985821&scene=142#wechat_redirect)和[趋势相对强度](https://mp.weixin.qq.com/s?__biz=MzkyODQ5MTIzNw==&mid=2247484206&idx=1&sn=c21e53ba53c3593493eafcbbfe711c1d&scene=142#wechat_redirect)。  
  
趋势温度指导时机，  
趋势强度指导选筹。  
  
推荐点开注解，理解指标含义和使用方法。图1  
  
虽有一定门槛，但一旦理解温度和强度，  
小程序将成为您顺势交易的最佳复盘工具。  
  
其他指标的介绍：  
[指标 | “右侧天数”指标公测上线](https://mp.weixin.qq.com/s?__biz=MzkyODQ5MTIzNw==&mid=2247486233&idx=1&sn=8af646b34e032b40ec5a859fa1c64ca7&scene=142#wechat_redirect)  
[止盈指标 | 开香槟、危险信号、波动率放大](https://mp.weixin.qq.com/s?__biz=MzkyODQ5MTIzNw==&mid=2247486908&idx=1&sn=9aa64d6b37d18ea4fa670fa58451f1bd&scene=142#wechat_redirect)  
  
3、传播趋势交易的理念。  
  
播客是最好的说明文档。  
  
如果您只关注房产，  
推荐听播客“[观点是个屁](https://mp.weixin.qq.com/s?__biz=MzIyMTYyMzg1OQ==&mid=2247492601&idx=1&sn=9702b307dd12da61055e9341783f1f0d&scene=142#wechat_redirect)”，  
  
如果您关注全大类资产，  
推荐听播客“[成为趋势动物](https://mp.weixin.qq.com/s?__biz=MzkyODQ5MTIzNw==&mid=2247486781&idx=1&sn=11cde2723387466529d70d4cc2175cca&scene=142#wechat_redirect)”。  
  
此处感谢主播老钱提供平台。  
  
详见趋势动物pro  
  
声明：交易无圣杯。仅供参考，请独立决策。  
Nick，2025/8/21
