# 20260111 山海经·神兽正式上线

山海经·神兽正式上线  
每个交易日更新，面向金融会员开放  
  
山海经·神兽是趋势小程序的隐藏彩蛋，  
唯一入口是搜索"山海经神兽"跳转。  
  
山海经大类是一个思想实验，  
帮助用户更好理解行情、趋势、交易。  
  
山海经共200+个神兽品种，  
分为五个经卷，东/西/南/北/中山经，  
所有神兽的日趋势由一系列随机数按规则生成。  
  
规则如下：  
  
1、每日涨跌幅为完全的随机数，概率符合正态分布，有涨有跌、均值为0；  
2、涨跌幅的波动率有所不同，神兽名字越长，波动率越大；  
3、每日成交额随机生成、与涨跌幅呈正相关；  
4、价格为累计净值；  
5、周度调整成分权重，每个交易日更新。  
  
设计"山海经"，是为了进行长期的行情实验，  
随机的神兽趋势，可和现实趋势行情对照。  
  
方便更深刻的理解——分散组合、大盘指数、观点基本面、单边趋势、动量危机、交易策略等理念。  
  
日后有机会再详细阐述。  
  
详见趋势动物pro
