# 更新 | 香港全量趋势正式上线

香港全量趋势正式上线。图1  
  
1、香港趋势改为自编香港住宅指数，  
更低噪、更平滑。  
每周一更新，与大陆其他城市同步。  
  
2、全量趋势包含：香港→行政区→板块→屋苑。  
  
3、单价默认单位是港元/呎，实用面积口径，简称“香港呎价”。  
  
如果想切换到大陆的元/平米，建筑面积口径，  
直接把汇率切换到“CNY人民币”即可。
