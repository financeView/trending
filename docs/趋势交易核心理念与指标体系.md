# 趋势交易核心理念与指标体系

> 调研来源：`reference/` 下微信长文转写的 Markdown（使用说明 + 更新日志 + 问答汇总）。  
> 目标：抽象可复用的趋势交易理念、度量方法与指标，为自建工具提供概念基线。  
> 说明：第三方产品公开理念的调研笔记，非投资建议；公式级细节原文多未公开。

---

## 1. 一句话定位

趋势工具本质是 **「趋势事实系统」**：持续度量价格趋势正在发生什么，用纪律把「时机」和「选筹」对齐到趋势——而不是用观点、预测或基本面故事决定持仓。

产品三个初衷（[`如何使用_如何使用趋势动物Pro.md`](../reference/如何使用_如何使用趋势动物Pro.md)）：

1. 全市场、全天候追踪趋势（房 / 股 / 商 / 债 / 衍）
2. 为顺势交易者提供决策参考（核心：温度 + 相对强度）
3. 传播趋势交易理念

核心口诀：

- **趋势决定持仓**（观点是个屁；观点也叫基本面）
- **温度定时机，强度定选筹**
- **价格趋势第一**（收益率由价格决定）
- **去多鱼的池塘钓鱼**（顺势战场 + 仓位）
- **留强汰弱**（一切买卖本质是置换）
- **截断亏损，让利润奔跑**

## 2. 核心理念

### 2.1 事实优先于观点

来源：[`更新日志_30_…观点…趋势.md`](../reference/更新日志_30_请各位读者自行区分「观点」和「趋势」.md)

| | 含义 |
|--|------|
| **观点** | 看法、预测、归因 |
| **趋势** | 不断变化更新的事实 |

纪律：

- 收益率由价格趋势决定；**趋势以外都是观点，观点也叫基本面**
- 观点再看好，趋势走坏 → 离场
- 观点再看空，趋势走好 → 建仓

大机会往往粗糙模糊、难归因、难共识；能明文写清并引发广泛共鸣的逻辑，多半不是机会（[`更新日志_40_….md`](../reference/更新日志_40_大的趋势机会来临的时候，%20体验是粗糙模糊、看不明说不清、摸石头过河、无历史可考、难以归因。.md)）。

### 2.2 价格趋势绝对核心

来源：问答汇总 Q8

- 追踪 **价格趋势** 是唯一重要的；成交量、挂牌、集中度、租金、基本面都是「其他」
- 涨就是涨，跌就是跌；勿用辅助指标合理化违背纪律的主观交易
- 图表默认 **对数坐标**：度量收益率/增速，不是绝对价格跳动；等距对数格可直接「数格子」估涨跌幅（[`使用说明_10_….md`](../reference/使用说明_10_8.%20为什么小程序用对数坐标？.md)）

### 2.3 右侧交易（顺势）

来源：[`使用说明_08_…趋势右侧.md`](../reference/使用说明_08_10.%20指标%20趋势右侧.md)、[`更新日志_11_…右侧天数….md`](../reference/更新日志_11_更新%20“右侧天数”指标公测上线.md)

系统服务顺势交易者，不是左侧抄底器。

| 事件 | 定义 |
|------|------|
| **进入右侧** | 温度**首次**触发「热」（状态机事件）。UI 标签「温转热」可表示开启**或延续确认**，见 §4.3 |
| **右侧存续** | 进入后温度未回到结束条件（可回落至「温」仍算存续；右侧天数继续累加） |
| **结束右侧** | 「温转平」：自建约定为温度回到「平」**及以下**；右侧天数清零 |

口径注意（文献冲突，字典层也须标明）：

- [`使用说明_08`](../reference/使用说明_08_10.%20指标%20趋势右侧.md)：结束条件写「降到平**以下**」  
- [`更新日志_11`](../reference/更新日志_11_更新%20“右侧天数”指标公测上线.md) / [`更新日志_09`](../reference/更新日志_09_止盈指标上线：开香槟、危险信号、波动率放大.md)：写「平**及以下**」  
- **自建约定**：采用「平及以下即破坏」（与止盈/止损纪律一致）；「恰为平」时按结束右侧处理。专文 08 的「平以下」不作唯一真值。

温度的**静态语义**（右侧天数文）≠ **右侧状态机**：

| 温度 | 静态位置语义 | 与右侧状态机的关系 |
|------|--------------|-------------------|
| 沸 / 热 | 右侧 | 热 = 进入确认；沸仍在右侧 |
| 温 | 准右侧 | **从未触发热**：仅准右侧，未进入；**已进右侧后回落到温**：右侧仍存续 |
| 平 | 无方向 | 自建约定：回落到平 → 结束右侧 |
| 凉 | 准左侧 | 结束右侧之后的偏空盘整 |
| 寒 / 冻 | 左侧 | 下跌确认 / 超跌区 |

大部分时间多数品种处于「非右侧」；精力应集中在有限右侧品种。  
反转策略可在「冻」左侧埋伏；趋势策略在「热」确认初期右侧建多。避免「沸时买、冻时卖」（最拥挤头寸方向）。
**买强不买弱**：与留强汰弱同属纪律内核；高开强势不宜改成「盘末再观察」（问答 Q82）。

### 2.4 温度 × 强度：时机与选筹

来源：[`使用说明_13_….md`](../reference/使用说明_13_5.%20「趋势温度」是分数，「趋势相对强度」是排名.md)、[`使用说明_16_….md`](../reference/使用说明_16_2.%20指标%20趋势相对强度.md)

| 指标 | 比喻 | 角色 |
|------|------|------|
| 趋势温度 | 考试分数（绝对体感） | **择时 / 节奏** |
| 趋势相对强度 | 年级/班级排名 | **选筹 / 方向** |

关键命题：

1. **强度高 ≠ 涨，强度低 ≠ 跌**——强度只是位次
2. 宏观熊市「全员不及格」时，排名仍有意义，但不等于可满仓做多
3. 投资既要「能涨」（温度），也要相对强弱（强度）
4. 强度高是领头羊 **必要不充分** 条件；用右侧确认区分「资金流入真强」与「低波动假强」
5. 强度适合周期启动初期观察；温度转热/沸后纯按强度追有追高风险
6. 强度高者常领先舆论（冷门）；需「事实 > 观点」的信念
7. **广度大于深度**：扩大品种池提升跨周期选筹能力

买入不宜只按强度排序：即使强度第一，未温转热（未进右侧）仍过早；推荐以温转热为精确时机（也可自定平转温等纪律）（问答 Q9）。

### 2.5 战场：先择市，再择股

来源：问答 Q2、[`更新日志_39_…右侧分布图….md`](../reference/更新日志_39_20260719%20趋势右侧分布图上线.md)

顺势逻辑：去赚钱效应好、处于右侧的战场。

战场度量：

1. 大类 / 行业 / 组合的 **温度、强度**
2. **温转热个数**
3. **右侧品种占比**（右侧分布图：黄=右侧，绿=下行）

原则：鱼多的池塘加大仓位，弱处降仓；顺势多做、逆势少做。  
放下「跑赢池塘」执念，用趋势做仓位管理更省力。  
总仓位亦可随战场：大类强度高且温度热 → 仓位可大；反之收（问答 Q38 思路）。

「温转热」不是预测圣杯：遍历全部温转热时，原文给出的胜率约 **35%**、盈亏比约 **2–3**（口述经验，非已验证产品承诺）。反模式是弱市严格执行、牛市不敢加仓。

### 2.6 机会成本：买卖 = 置换

来源：问答 Q7、强度专文

一切买卖先问：钱从哪来？卖掉做什么？本质是「卖 A 买 B」。

- 持有弱品种承担机会成本（跑输）
- 跌得少也可能是相对跑赢
- 置换时机倾向：B **温转热**，或 A **转平**（底线凉转寒）
- 收藏夹跨大类强度排序，服务于留强汰弱

现金也是大类的一种；不必单吊一个大类，大类机会轮动（问答 Q13）。

### 2.7 纪律 = 策略

来源：问答 Q1、Q10

工具帮用户建自己的顺势系统，不是唯一荐股答案。玩法可变体：波段、弱转强、分仓、单吊、打板、龙头、截面、择时增强等。

**纪律自查四条**：

1. 简单清晰：选股 / 买 / 卖 / 仓位无冲突、可执行  
2. 截断亏损：须有止损（例：温转平无条件离场）  
3. 让利润奔跑：忌过早兑现肥尾（见大暑必平、涨 30% 必走、人为限制主线暴露等）  
4. 匹配性格：周期、股池、流动性、大类偏好  

**三个门槛**（难度递增）：

1. 接受追涨杀跌，学会右侧 / 温转热 / 温转平 / 节气（入门）  
2. 按纪律择时，学会梭哈超仓与吓尿空仓（数月 + 完整趋势）  
3. 真正严格执行，放弃沉迷策略优化（数年或顿悟）  

执行习惯：

- 盘中不抢跑；盘后信号，次日开盘对齐  
- 控制个股上限做分散；**可不强制行业分散**（主线暴露可以很高）  
- 新手：基本面股池 + 趋势执行（观察池 / 持仓）；进阶常弱化基本面  
- 股池 50–100：单票约 5%–10%；>200：单票约 2%  
- 须能接受反复止损；**危险信号优先于「等温转平」**（风险优先于收益，问答 Q14）
- 破产四忌（问答 Q80 原文）：「破产小秘诀：逆势、扛单、重仓、不分散。四条里哪怕有一条做不到，也很难破产。」
- 股池纪律勿漂移：信号来了不该临时扩大股池去「温转热列表里随便加」（问答 Q82）
- 温转热首日：胜率通常更高，但右侧越后期潜在盈亏比越高（问答 Q25）；无标准答案，靠纪律
- 评价交易：关注项目级胜率/盈亏比，过度盯收益率易诱发「跑赢大盘」而破坏顺势纪律（问答 Q22）
- 不交易 / 空仓也是决策；与「吓尿空仓」门槛一致（问答 Q30 等）

### 2.8 层级与流动性

- 风格 / 板块 / 区域 / 城市温度，比稀疏成交的小区更可靠；级别越低噪音越大  
- 低流通可呈「心电图」；上溯板块 / 风格 / 成交主力同类。例外：稀缺价值龙头等也可能曲线抖但流动性不差，勿一律判低置信（[`使用说明_14`](../reference/使用说明_14_4.%20小区趋势像心电图，是不是不准？.md)）  
- 高 beta 期率先转「热」的层级 = 领头羊候选  
- 样本不足的温转热 / 温转平，置信度低，宜用上级品种（问答 Q19）；房产侧成交充分可参考「年成交 >20 套 / 成交主力」（卖房专文）

## 3. 度量方法

### 3.1 对象层级

```
大类资产 → 市场/国家 → 行业/风格/组合 → 板块/主题 → 个股/小区/合约
```

同构输出温度、强度、右侧状态；支持自上而下择战场、自下而上校验噪音。

### 3.2 更新节奏

来源：[`更新日志_31_….md`](../reference/更新日志_31_趋势更新规则如下.md)

| 资产 | 更新 |
|------|------|
| 全国房产 | 每周一上午 |
| A 股 / ETF / REITs | 交易日 16:30 |
| 港股 / 商品 / 转债 | 交易日 17:30 |
| 美股 / 全球股指 / 债券 | 次日 8:30 |

信号对齐：T 日盘后更新 → T+1 开盘执行。

### 3.3 三个正交轴

1. **绝对状态（温度）** — 自身阶段：多 / 空 / 无序  
2. **相对排名（强度）** — 在选定宇宙内的分位  
3. **生命周期（右侧 + 天数 + 节气）** — 右侧早晚段  

辅助：同比/环比、止盈/风控标签（开香槟、波动率放大、危险信号）、活跃/成交、租息（房产）。

### 3.4 强度宇宙

分两层理解，勿混为一谈：

**A. 显示宇宙**（UI 可见，[`更新日志_27`](../reference/更新日志_27_说明%20为什么收藏夹的趋势强度和详情页不一样？.md)）

| 显示宇宙 | 含义 | 用途 |
|----------|------|------|
| 详情页 / 同大类 | 「年级排名」（例：跑赢 21% 的 ETF） | 单市场选筹 |
| 页面内 | 当前列表/组合内分位 | 同页排序 |
| 收藏夹 | 自选池分位（「班级排名」） | 跨大类置换 |

**B. API 字段**（问答 Q6 命名 Local / Global；语义有文献歧义）

| 字段 | 问答 Q6 字面映射 | 同答后文使用建议 | 自建注意 |
|------|------------------|------------------|----------|
| Local | 与「A 股内排名」并列提出 | 只做单市场时用市场内分位 | 当作「当前主市场宇宙」字段名，以接入指南/实测为准 |
| Global | 与「页面内排名」并列提出 | 跨大类对比必须用 Global | **勿**仅凭字面断定 Global=页面内或 Global=固定全资产宇宙；跨池比较时再选更大宇宙 |

文献冲突摘要：Q6 先把页面两种排名依次对应 Local/Global，后又要求跨大类用 Global——与「页面内=Global」矛盾。自建应：**显示宇宙**按详情页/页面/收藏夹实现；**API 字段**以实测文档为准，本文不把「Global=全资产」写成定论。

宇宙变分数，通常不改变两品种相对先后（原文断言）。UI/API 必须标明宇宙。

### 3.5 右侧状态机

```
非右侧 ──(温度首次达到「热」)──► 右侧
         │  含平→热、温→沸等「右侧开启」情形
         │  此时右侧天数从 0 开始计数
右侧   ──(温度回到「平」及以下 / 温转平)──► 非右侧
         │  ※ 自建约定「平及以下」；专文 08 曾写「平以下」
         │  右侧天数清零

右侧存续期内：
  - 温度可为 温 / 热 / 沸（回落到温 ≠ 结束）
  - 「温转热」标签可能再次出现 = 延续确认，≠ 重新进入，≠ 重置天数
  - 右侧天数按自然日 +1（含非交易日）
节气：仅右侧=true 的品种计算
```

结束条件不是语料唯一真值，而是自建落盘约定（与 §2.3 / §4.1 / §4.5 一致）。

### 3.6 决策流水线

```
1. 择战场：大类/行业温度·强度·右侧占比·温转热密度
2. 择时机：温转热（或自定平转温）；避沸追买、冻追杀
3. 择标的：强度高 + 流通充分 +（可选）活跃
4. 定仓位：顺势进攻 / 无序降仓；个股上限，行业可不强制分散
5. 管持仓：留强汰弱；危险信号优先离场；沸/开香槟/波动放大分批止盈；温转平离场
6. 复盘：胜率、盈亏比、周期、数量 vs 纪律
```

仓位参考：战场热且强度高时可加大总仓；股池内符合纪律的尽量买满，买不过来则收紧选股门槛（问答 Q20）。

## 4. 衡量指标字典

### 4.1 趋势温度（绝对体感）

来源：[`使用说明_17_…趋势温度.md`](../reference/使用说明_17_1.%20指标%20趋势温度.md)

| 档位 | 含义（原文） | 买方 | 卖方 |
|------|--------------|------|------|
| 沸 | 快速拉升、波动放大 | 警惕尾声 | 可分批兑现（见止盈：沸/开香槟） |
| 热 | 上涨行情 | 尽快建仓 | 不宜卖 |
| 温 | 盘整，有即将启动上涨的迹象（准右侧） | 密切监测 | 不宜卖 |
| 平 | 横盘无方向 | 观望 | 观望 |
| 凉 | 盘整，有即将启动下跌的迹象（准左侧） | 谨慎 | 监测卖出 |
| 寒 | 下跌行情 | 不宜买 | 凉转寒初期斩仓 |
| 冻 | 快速下跌、波动放大（超跌区） | 反转可左侧埋伏 | 慎恐慌杀跌 |

口诀：升势温预警 / 热确认 / 沸泡沫；跌势凉预警 / 寒确认 / 冻超跌区。

与右侧状态机（字典层复述，避免只读本表遗漏歧义）：

- **进入**：首次达「热」（可含平→热、温→沸等）
- **存续**：已进右侧后，温度可为温/热/沸；回落到温 ≠ 结束
- **结束（自建约定）**：回到「平」**及以下**（与 §2.3 / 止盈文一致）；专文 08 曾写「平以下」——「恰为平」时按结束处理

### 4.2 趋势相对强度（0–100 分位）

来源：[`使用说明_16_….md`](../reference/使用说明_16_2.%20指标%20趋势相对强度.md)

灵感：William O'Neil RS，楼市/多资产改良。

| 分数 | 解读 |
|------|------|
| 90–100 | 领头、极强势 |
| 70–90 | 靠前、强势 |
| 50–70 | 中上、偏强 |
| 30–50 | 中下、偏弱 |
| 10–30 | 靠后、弱势 |
| 0–10 | 倒数、极弱势 |

高者常 **量价双好**（相对放量/流通 + 相对坚挺/领涨）。  
买方：周期启动（温度转暖）时建仓领头羊风格/主题。  
卖方/置换：持续留强汰弱；强度更适置换而非单纯「能不能卖」。

### 4.3 温转热 / 温转平 / 右侧天数

拆开两个概念，避免实现时把标签当成「每次进入」：

| 概念 | 含义 | 对状态机的影响 |
|------|------|----------------|
| **进入右侧（事件）** | 温度**首次**触发「热」（含平→热、温→沸等开启情形） | 右侧=true，天数从 0 起算 |
| **温转热（标签）** | 当天由温转热，或更广的「右侧开启**或延续确认**」（[`更新日志_07`](../reference/更新日志_07_更新%20“温转热”标签上线.md)、[`使用说明_08`](../reference/使用说明_08_10.%20指标%20趋势右侧.md)） | 开启时等同进入；**延续时不重置天数** |
| **温转平（标签）** | 右侧结束信号 | 右侧=false，天数清零；可映射无条件止盈或止损 |
| **右侧天数** | 确认右侧至今持续天数（自然日） | 偏好早期；回避后期尤其波动率放大 |

### 4.4 趋势节气（右侧阶段）

来源：[`使用说明_07_…趋势节气.md`](../reference/使用说明_07_11.%20指标%20趋势节气.md)

仅右侧品种有标签；回答「右侧走到哪」，不单独回答「能不能买」。

| 节气 | 阶段 |
|------|------|
| 谷雨 | 右侧震荡、蛰伏 |
| 立夏 | 一阶段、萌芽 |
| 夏至 | 二阶段、发展 |
| 小暑 | 三阶段、破圈（加速） |
| 大暑 | 四阶段、爆发（后段拥挤剧烈） |
| 立秋 | 右侧结束 |

- 稳健：偏立夏/夏至，尽量小暑前开仓  
- 激进：小暑/大暑可短做，须短周期与离场觉悟  
- **不保证走完顺序**；可随时结束右侧  
- 也可完全不看节气、全部平铺——长期仍可有效，前提是坚持纪律（问答 Q16）；勿把节气做成强制门控  

下行节气在语料中无正式定义：问答 Q44 的散户行为段子出现过「立冬→小寒→大寒→立春」等命名，暗示下行节气体系存在但未公开（见 §7 算法缺口）。

### 4.5 离场 / 风控标签

来源：[`更新日志_09_…止盈指标….md`](../reference/更新日志_09_止盈指标上线：开香槟、危险信号、波动率放大.md)

| 策略 | 信号 | 动作 |
|------|------|------|
| 超常规上涨 | 沸、波动率放大、开香槟 | 分仓止盈、部分减仓 |
| 超常规回撤 | 危险信号（不正常放量超卖） | **优先**平仓观望（不必等温转平）；解除后再右侧开仓 |
| 趋势转弱 | 温度降至平及以下（自建约定；专文 08 曾写平以下） | 无条件止盈**或**止损离场 |

简化规则：开香槟 = 连续跑赢超涨、炫耀机制；波动率放大 = 右侧后期信号。  

问答补充（Q21）：沸与开香槟 **异曲同工**，多为 **轻度/分仓止盈**，不是必须完全清仓；作者实践是下次温转热再加回。

### 4.6 辅助指标

| 指标 | 要点 |
|------|------|
| 同比 / 环比 | 中短期跌速；同比仍负但爬升 → 跌速收窄、复苏信号 |
| 租息 | 四档：≥4.5% 高（以租养贷）；3.0–4.5% 中高（超房贷利率）；1.7–3.0% 中（超十年国债）；<1.7% 低；档位随利率自行调整；覆盖近一年跌幅且显著高于国债收益率时，不建议裸卖 |
| 活跃 | 近 20 日显著放量或大涨（如个股单日 >5%）；大类/板块右侧下优先选活跃 |
| 价值龙头（房产） | 城市高总价且流通好的 top20 小区（[`更新日志_10`](../reference/更新日志_10_“价值龙头”、“趋势龙头”小区标签上线.md)） |
| 趋势龙头（房产） | 各板块强度最高且已进右侧的小区集合 |
| 趋势龙头（股市） | 与房产不同：问答 Q37 — 全市场强度 Top40；行业趋势龙头 = 各行业 Top4 |
| 风格指数 | 区域/能级/业态/楼龄/租息等截面降噪 |
| 成交额 | 流动性与可信度 |
| 右侧分布图 | 发现多鱼池塘 |
| 计价货币 | 多币种同一趋势 |

「龙头」标签**随资产域定义不同**，实现时分域配置，勿混用小区规则到个股。

### 4.7 买方 / 卖方清单

**买方**：温监测 → 热建仓 → 沸警惕；强度高领头羊；右侧早期 + 上级共振；可选活跃；买强不买弱。  

**卖方**：凉监测 → 寒（凉转寒初期）斩仓 → 冻警惕尾声；多套优先卖强度低、留强度高（成交充分）；好卖的未必该卖；危险信号优先离场。

## 5. 指标关系

```text
┌──────────────────┐
│ 战场：大类/行业   │
│ 温度·强度·右侧%  │
└────────┬─────────┘
         │ 适合做趋势？
         ▼
┌─────────────────────────┐
│ 温度 → 时机/节奏         │
│ 强度 → 选筹/置换         │
└────────────┬────────────┘
             │ 首次达「热」→ 进入右侧
             │ （温转热标签 = 进入或延续，延续不重置天数）
             ▼
┌─────────────────────────┐
│ 右侧天数 + 趋势节气     │
└────────────┬────────────┘
             │
┌────────────┼────────────┐
▼            ▼            ▼
开香槟/波动放大   危险信号   温转平
（分仓止盈）    （应急优先） （转弱离场：
                           止盈或止损）
```
