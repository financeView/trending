# Exit tags (止盈辅助标签) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship metrics §11 exit tags behind `exit_tags_enabled: true` (`p05-v4`): stock gets `vol_expand`/`champagne`/`danger`; L2 gets first two only; digest「止盈」column; display-only (no fill).

**Architecture:** Pure `scripts/metrics/exit_tags.py` after peer RS + stock VOL; `replay_from_ohlc` copies `sigma_pctile` onto snaps; L2 uses cached synth OHLC (no Σamount this slice). Persist `tags` JSON TEXT on `daily_*`. Soft `tag_rate_cap` warn on stderr.

**Tech Stack:** Python 3.11, PyYAML, SQLite `trend.db`, pytest, stdlib `statistics.median` / `json`.

## Global Constraints

- Spec: [`2026-10-11-exit-tags-design.md`](../specs/2026-10-11-exit-tags-design.md) (CR2 final)
- Sister (later): [`2026-10-11-basket-vol-score-design.md`](../specs/2026-10-11-basket-vol-score-design.md) — do **not** add synth Σamount / basket VOL / L2 `danger` here

- Champagne: last `champ_k` spine days; any miss fails; peer set = asof-frozen (a)
- L1 `tags=[]` always; L2 must not contain `danger` after this plan alone
- Prefer `.venv/bin/pytest` when present; do not commit dirty `data/cache/*`

### Task 3: Pure `exit_tags` module + goldens

**Depends on:** Task 0.

**Files:**
- Create: `scripts/metrics/exit_tags.py`
- Modify: `tests/test_exit_tags.py`

**Interfaces:**
- Produces:
  - `TAG_ORDER = ("vol_expand", "champagne", "danger")`
  - `TAG_DISPLAY = {"vol_expand": "波动率放大", "champagne": "开香槟", "danger": "危险信号"}`
  - `format_tags_display(tags: Sequence[str]) -> str`  #顿号 join display names
  - `tags_to_sql(tags: Sequence[str]) -> str`  # `json.dumps(list, ensure_ascii=False)` stable order
  - `assign_exit_tags(stock_rows, l2_rows, l1_rows, *, params, bar_cache, l2_synth_by_code, quarantine: set[str] | None = None, trade_date: str) -> dict`  
    rates_meta: e.g. `{"stock": rate, "l2": rate, "l1": 0.0}`  
    Mutates only `tags` on rows; L1 always `[]`; L2 never appends `danger` in this module version (gate: `enable_l2_danger: bool = False` kwarg default False — basket VOL plan flips True)
  - Helpers OK: `daily_returns(closes)`, champagne/danger/vol_expand predicates

**Algorithm notes (Spec §3.2):**
- `vol_expand`: truthy `right_side` ∧ `solar_term in {"小暑","大暑"}` ∧ `_sigma_pctile >= vol_expand_pctile`
- Champagne: spine last `champ_k` days; each day ret finite and `> median(rets of asof peer set that day)`; sum(ret-median) ≥ `champ_excess`
- Peer stock: codes where `stock_peer_eligible(row, quarantine=...)` on **asof rows**; L2: `basket_peer_eligible`
- Danger (stock only): **window-then-rank** (align Spec C VOL / Spec §3.2):  
  `start = max(0, t+1-vol_hist)`; `window = rets[start:t+1]` (same for amounts);  
  require today finite and `finite_n > 1`;  
  `p = scores_0_100(window)[-1] / 100.0`; then `p_ret ≤ danger_ret_pctile` ∧ `p_amt ≥ danger_amt_pctile`.  
  **Forbidden:** `scores_0_100(full_spine_rets)[t]` (ranks vs all history, not the window).
- Flag off: all `tags=[]`, skip compute
